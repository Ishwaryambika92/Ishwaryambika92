## 🧠 What is RAG?

**Retrieval-Augmented Generation (RAG)** combines a language model with a knowledge retrieval system. Instead of relying only on what the model already knows, RAG searches relevant content (like transcript chunks) and feeds it to the model as context. This allows for accurate, grounded answers to questions about specific documents, meetings, or videos — reducing hallucination and improving relevance.
